# 理论地图

> 用法：不必一次读完。**卡壳时、需要升级提问深度时、或者要给某个归纳找理论支撑时**，回来查对应条目。
> 每条都标注了「这句理论 → 你该问什么」。

---

## 一、为什么需要萃取（存在性理由）

**波兰尼 · 隐性知识**
> 我们知道的，远多于我们能说出来的。

知识分两类：能用语言/公式/手册表达的（显性），与只存在于行动中、连本人都难以言明的（隐性）。隐性知识与显性知识交叉出四象限：已知能说、已知说不出（这就是萃取的目标区）、不知能说、不知也说不出。

→ **决定了你该问什么**：不要问"你的方法论是什么"（他会编一个给你），要问"那一次你具体做了什么、当时脑子里在想什么"。

**野中郁次郎 · SECI 知识创造螺旋**
四种转化：潜移默化（Socialization）→ **外显化（Externalization）** → 汇总组合（Combination）→ 内化（Internalization）。

→ **萃取 = 外显化这一步**。所以你的产出必须是"可被语言/模型/清单承载"的形态，不能停在"氛围""感觉"层面。

**詹姆斯·马奇 ·《经验的疆界》**
两种学习：低智学习（试错、复制成功）与高智学习（建模、叙述）；经验的三个陷阱——历史过于复杂、因果模糊、人类智力的限度。

→ **给你的提醒**：萃取出来的"经验"不等于"真理"。在成品里要肯留下"该经验适用的边界"，不要把它包装成普适规律。这也是"待深化方向"那一节存在的理由。

## 二、从哪下手（取样方法）

**Flanagan · 关键事件法 CIT（1954）**
不记录全部行为，只记录"造成成功与失败差异"的那些关键行为。

→ **决定了你该问什么**："给我一次具体的"而不是"讲讲你平时怎么做"。一次典型成功事件的信息密度，远高于十次泛泛概述。

**McClelland / McBer · 行为事件访谈 BEI**
以 STAR（Situation-Task-Action-Result）为骨架，只追问可观察的行为与当时的想法。

→ **决定了你该问什么**：一旦受访者跳到评价层（"我觉得关键是沟通"），立刻追问"说一件能体现这件事的具体事"。

**Annett · 层级任务分析 HTA / DACUM 工作任务分析**
岗位 → 任务 → 步骤 → 操作标准，逐级下钻。

→ **用在哪**：萃取对象是操作性、重复性强的岗位（产线、客服、实施）时，用它做补结构，能捞出"隐性步骤"。

## 三、怎么把脑子里的东西挖出来（核心）

**Klein · 认知任务分析 CTA 与关键决策法 CDM**
专家Expertise 藏在判断里，不在动作里。CDM 的认知探针：

| 探针 | 问法 |
|---|---|
| 线索 | 你当时第一眼注意到的是什么？哪里"不太对劲"？ |
| 目标 | 那一刻你在试图同时保住哪几样东西？ |
| 假设 | 你当时默认了什么一定成立？ |
| 不确定性 | 哪里你也没把握？你怎么处理的？ |
| Aha 时刻 | 什么时候你突然明白过来？之前和之后想法有什么不同？ |

→ **决定了你该问什么**：CDM 探针是"第二梯队"武器。当常规 STAR 追问拿不到深度时使用。

**Klein · 自然决策 NDM 与识别启动决策 RPD**
真实场景中高手不比较选项，而是"一眼认出这是哪一类局面"，然后做心智模拟验证。

→ **决定了你该问什么**：问**"你一眼看见什么不对"**，而不是"你考虑了哪些方案"。后者是新手路径，问了也白问。

**Ericsson · 刻意练习 / Chase & Simon · 专家表征**
专家差异不在工龄，在心理表征的质量——他们"看到"的不是同一个世界（棋手看到棋局组块，新手看到单个棋子）。

→ **决定了你该问什么**："同样一份报告/同一个现场，你能看出什么是别人看不出来的？"这是拉开差距的关键一问。

**Collins 等 · 认知学徒制 / Lave & Wenger · 情境学习**
认知学徒四环节：建模 → 辅导 → 脚手架（逐步撤离）→ **清晰表达**。学习的本质是进入"实践共同体"。

→ **决定了你的产出形态**：手册要有可模仿的动作模型 + 逐步放手的设计，不能只有原则。

**舍恩 · 反思性实践**
行动中反思（reflection-in-action）与行动后反思（reflection-on-action）。

→ **决定了你该问什么**："你在做这件事的过程中，有哪一刻临时改了主意？为什么？"——捕捉行动中的调整，比事后复盘更真实。

## 四、怎么判断值不值得做 / 什么该剔除

**Thomas Gilbert · 行为工程模型 BEM**
环境侧三要素：信息、资源、激励；个人侧三要素：知识/技能、能力、动机。

> 一线实践中常简化为三维归因：**能力问题 / 制度（规则）问题 / 权限（资源）问题**。

→ **决定了你该问什么**（也是最容易被漏掉的一组）：
- "这个困难，说到底是当事人不会做，还是制度让他没法做？"
- "如果是后者，这件事该由谁来解决？"
- **"哪些痛点是你这个方案（培训/工作坊/手册）根本治不好的？"**
> 这一步必须在交付之前完成。把治不好的痛点带进方案，只会导致现场失控或交付物无人认领。

**Rummler-Brache · 三层面绩效（组织 / 流程 / 岗位）**
→ 用来判断痛点落在哪一层，避免"什么问题都用培训解决"。

## 五、怎么组织与表达

**芭芭拉·明托 · 金字塔原理 / SCQA**
结论先行、以上统下、归类分组、逻辑递进。

→ **决定了产出怎么看**：任何成果第一屏必须有"一句话结论 + 全景结构"，不要让人读到最后才知道你要说什么。

**ORID 焦点讨论法**（Stanfield）
事实 O → 感受 R → 理解 I → 决定 D。

→ **决定了访谈顺序**：先 Oscillate 事实层（不带评价），再往下。**过早跳到 I/D 层会让受访者开始讲道理。**

**加涅九段教学法 / 梅里尔首要教学原理**
聚焦问题 → 激活旧知 → 示证新知 → 应用新知 → 融会贯通。

→ **决定了手册怎么排**：不能直接给步骤，要先给"你会遇到什么问题"的场景。

## 六、怎么让人真的用起来

**Baldwin & Ford · 培训迁移模型** / **柯氏四级评估**
学习只是起点，真正决定价值的是迁移氛围与环境支持。

→ **决定了你该问什么**："后来呢？这套东西别人真的用起来了吗？谁在用？用在哪？"

**Amy Edmondson · 心理安全感**
人只有在不必担心负面后果时才愿意开口。

→ **决定了现场的降门槛设计**：面对沉默者，**第一次开口的行为价值 > 他说了什么内容**。降低提问层级（"有没有补充"优于"你的看法是什么"），允许"没有补充"也算参与。

**721 法则**
70% 来自工作实践，20% 来自他人，10% 来自正式培训。

→ **决定了产出定位**：手册的价值在于"降低第一次照做的门槛"，不是替代实践。别把它写成一本教科书。
