# 素材编码表（模式 B）

> 用于直接分析访谈转写稿、会议纪要、聊天记录、复盘笔记。
> 目标：从一堆话里，把「隐性的东西」挑出来标清楚。

---

## 一、先决定这段代码属于哪一类

| 标记 | 含义 | 典型信号 |
|---|---|---|
| `[S] 情境` | 时间、地点、人物、角色、约束条件 | "那时候是三月份""客户那边只有两个人" |
| `[P] 痛点/挑战` | 当时真正难的地方 | "最麻烦的是""卡在这儿了" |
| `[D] 决策点` | 面临岔路、做了取舍的时刻 | "我当时想了想还是……""最后决定" |
| `[R] 判断依据` | 为什么这么选（**最常被略过**） | "因为我觉得""按以往的经验""我看他表情不对" |
| `[A] 动作` | 实际做了什么、说了什么原话 | "我就跟他说……""我先把 XXX 关了" |
| `[O] 结果` | 可验证的产出或后续影响 | "第二天""后来他们一直用""复购了" |
| `[X] 隐性原则` | 他自己总结不出，但反复出现的行为规律 | 从多处动作中归纳出来 |
| `[?] 待补` | 素材里的空白，必须回问受访者 | 见下文第三节 |

---

## 二、分析流程

**第 1 步｜通读一遍，不做归纳**
只标 `[S]` 和 `[A]`，建立事件的时间线。**这一步严禁提炼。**

**第 2 步｜找决策点**
沿时间线找岔路口：哪里他本可以那么做却没那么做？标 `[D]`。

**第 3 步｜补判断依据（最关键）**
对每个 `[D]` 问：**素材里有说为什么吗？**
- 有 → 标 `[R]`
- 没有 → 标 `[?]`，记入待补问清单
> 经验值：一段 30 分钟的访谈，通常有 3～8 处被略过的判断依据。**这些是整个素材里最值钱的东西。**

**第 4 步｜归纳隐性原则**
看哪些动作在不同情境下反复出现 → `[X]`。
> 检验标准：如果他本人听到这条会愣一下然后说"好像是"，就对了。如果他会说"这不是明摆着的吗"，说明太浅。

**第 5 步｜区分事实与推断**
- 素材里明确说了 → 事实
- 你归纳出来的 → 推断，**必须在输出里标注**

**第 6 步｜出清单**
向用户输出两样东西，然后才走"文字框架确认 → 出文件"的节奏：

```
【证据清单】事实层有哪些（含可引用的原话）
【待补问清单】哪些关键点素材没cover到，建议向受访者补问
```

---

## 三、待补问清单的常见类型

| 缺口 | 应该补问什么 |
|---|---|
| 缺成功标准 | "你们当时怎么就算成了？" |
| 缺判断依据 | "那一刻你是怎么判断该这么做的？" |
| 缺反例 | "有没有做过但失败的时候？" |
| 缺规模数据 | "涉及多少人？持续多久？" |
| 缺后续验证 | "后来这套东西真的被用起来了吗？" |
| 缺边界 | "什么样的情况下你这套做法不适用？" |

---

## 四、素材质量三问（先判断这段素材够不够用）

1. **有没有具体事件？** 全是评价和方法论 → 素材不可用，建议转模式 A 重新访谈。
2. **有没有结果证据？** 没有结果 → 无法验证，产出物要标注"未经验证"。
3. **有没有反面信息？** 全是成功叙述 → 高度可疑，要多问失败与例外。

---

## 五、口语素材的清洗要点

转写稿里这些可以安全剔除：语气词（嗯、那个、就是说）、重复、寒暄、转写错误、重复确认词。

**不能剔除的**：说话人原话、数字、时间、专有名词、客户/人名（输出时按需要做脱敏替换）。

**时间戳与说话人标签**（srt/vtt）要保留用于定位，但最终产出里不出现。

---

## 六、多份素材的处理

如果一次给了多份（例如同一个人被访了三次，或多个人的访谈）：

1. **先各自独立标记**，不要混。
2. 交叉比对：**同一件事在不同人嘴里不一样的地方，是最有价值的**——差异暴露了各自的隐性假设。
3. 冲突处标 `[?]`，进待补问清单。
